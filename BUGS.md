| # | Severity | Issue | Where | Description |
|---|----------|-------|-------|-------------|
| 1 | ~~**CRITICAL**~~ **FIXED** | Shallow merge loses sites on Nostr restore | `app.js:820,833` | **Fixed:** replaced shallow spread with deep-merge loop (higher nonce wins) in both `tryApplyBackup` code paths. |
| 2 | ~~**CRITICAL**~~ **FIXED** | `restoreFromId` replaces instead of merging | `app.js:2307` | **Fixed:** replaced full replacement with guarded deep-merge loop (higher nonce wins). |

| 5 | ~~**HIGH**~~ **FIXED** | No master password minimum length | `app.js:1392` | **Fixed:** added `MIN_PASSWORD_LENGTH = 8` constant and validation in both `setMasterPassword()` and `showBackupPasswordModal()` (set/change modes only — existing short passwords can still unlock). |
| 6 | ~~**HIGH**~~ **FIXED** | CryptoJS AES uses weak key derivation (EVP_BytesToKey/MD5) | `app.js` | **Fixed:** replaced CryptoJS.AES with Web Crypto API (PBKDF2-SHA256, 600k iterations, AES-256-GCM) for `saveLocalNonceBackup()` and `autoSaveVault()`. | 8 | ~~**HIGH**~~ **FIXED** | Lock-without-password UX is confusing | `app.js:918` | **Fixed:** extended `showConfirm()` with custom button labels and danger styling. Replaced two confusing dialogs with a single dialog: "Set Password" (primary) / "Lock Anyway" (danger red). |
| 9 | ~~MEDIUM~~ **FIXED** | Service worker cache update silently fails | `sw.js:39-43` | **Fixed:** clone response before `cache.put()`, return original response. Cache now updates correctly in the background. |
| 10 | ~~MEDIUM~~ **FIXED** | `_backupDebounceTimer` not cleared on lock/delete | `app.js:884-940,1377-1398` | **Fixed:** `lockVault()` now clears `_backupDebounceTimer` alongside the other timers. |
| 11 | ~~MEDIUM~~ **FIXED** | `popstate` handler skips screen-specific setup | `app.js:2579-2587` | **Fixed:** popstate handler now calls `showScreen()` instead of directly toggling CSS classes. |
| 12 | ~~MEDIUM~~ **FIXED** | HTML CSP missing `'self'` in `connect-src` | `index.html:5` | **Fixed:** added `'self'` to `connect-src` and added `object-src 'none'`, `frame-ancestors 'none'` directives. |
| 13 | MEDIUM | Race condition: remote restore during active use | `app.js:750-772` | `checkForRemoteBackups()` runs asynchronously after vault init. If the user starts adding sites while the loading modal is up, the remote restore could complete and overwrite them via the shallow merge (#1). The loading modal mitigates this somewhat, but doesn't fully block interaction. |
| 14 | LOW | `generateNewSeed` sets `vault.seedPhrase` before verification | `app.js:572` | The seed phrase is stored in `vault.seedPhrase` as soon as it's generated, before the user verifies they've backed it up. If they navigate away without completing verification, an unverified seed is in memory and could be acted upon. |
| 15 | ~~LOW~~ **FIXED** | `escapeJsString` is defined but never used | `app.js:1081-1083` | **Fixed:** removed dead code. |
| 16 | ~~LOW~~ **FIXED** | `toggleDebugMode` triggers Nostr backup | `app.js:1601` | **Fixed:** removed `backupToNostrDebounced()` call from `toggleDebugMode()` — debug mode is a UI preference, not vault data. |
| 17 | LOW | Seed words rendered via `innerHTML` without escaping | `app.js:580,1637` | `div.innerHTML = \`<span>${i + 1}.</span>${word}\`` — BIP39 words are safe (a-z only), so this isn't exploitable in practice, but it breaks the escaping convention used elsewhere (`escapeHtml` in `renderSiteList`). |
| 18 | ~~LOW~~ **FIXED** | No validation on nonce values from imports/backups | `app.js:1551-1558` | **Fixed:** `mergeUsers()` now validates nonces with `Number.isInteger(nonce) && nonce >= 0`, skipping invalid values. |
